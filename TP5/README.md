### Resumo:
    1. Criar o json-server com o dataset cinema.json
     2. Usar o express para criar uma aplicação web que sustente as seguintes rotas:
     	a. GET / ou /filmes => id, titulo, ano,#gen-numero de generos associados ao filme, #cast-numero de atores;
     	b. GET /filmes/:id => toda a inform do filme;
     	c. GET /atores => tabela com ator, nºde filmes que ele entra
     	d. GET  /atores/:id => pagina do ator com toda a informaçao
     	extra. o mesmo para o genero
